# ML-Project

Machine learning models for predicting the solubility of chemical compounds based on molecular descriptors using linear regression and random forest.

## Overview

This project implements machine learning models to predict chemical compound solubility. It uses molecular descriptors as features to train and evaluate both linear regression and random forest models.

## Features

- Linear Regression Model
- Random Forest Model
- Molecular descriptor-based feature engineering
- Model comparison and evaluation

## Technologies Used

- **Language**: Python (Jupyter Notebooks)
- **Libraries**: scikit-learn, pandas, numpy
- **Notebooks**: Interactive machine learning experiments

## Getting Started

### Prerequisites

- Python 3.x
- Required Python packages (see requirements or notebooks)

### Running the Project

The project uses Jupyter Notebooks for interactive analysis and model development. To get started:

1. Clone the repository
2. Install required dependencies
3. Open and run the Jupyter notebooks

## Project Structure

This repository contains Jupyter notebooks with machine learning models and analysis for solubility prediction.
